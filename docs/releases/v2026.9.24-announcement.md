# AIWG 2026.9.24 - Deterministic dispatch cap test

AIWG 2026.9.24 is a corrective release that unblocks npmjs publication: the
parallelism-cap test now holds saturated dispatch slots for the whole cap
check.

## What changed

- **Dispatch cap test:** the cap assertion saturated slots with 250ms tasks
  while the 5th dispatch's own admission work can outlast them on loaded
  runners. Saturating tasks now hold for 8s so the check runs against
  genuinely saturated slots.

## Try it

Update with `npm install -g aiwg@2026.9.24`. The
[versioning guide](../contributing/versioning.md) describes the stable-channel
policy.

The full change history is in the
[changelog](https://github.com/jmagly/aiwg/blob/v2026.9.24/CHANGELOG.md).
